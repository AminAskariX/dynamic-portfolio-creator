## 🇮🇷 فارسی

قالب سادهٔ نمونه‌کار شخصی با HTML، CSS و JavaScript برای معرفی، نمایش پروژه‌ها و بخش تماس.

### 🚀 امکانات

- صفحهٔ تک‌صفحه‌ای با بخش‌های معرفی، درباره، پروژه‌ها و تماس.
- تغییر حالت روشن و تیره با دکمهٔ صفحه.
- فرم تماس با اعتبارسنجی فیلدها و باز کردن پیش‌نویس در برنامهٔ ایمیل کاربر.

### 🛠️ اجرا و سفارشی‌سازی

1. مخزن را دریافت کنید: `git clone https://github.com/AminAskariX/dynamic-portfolio-creator.git`.
2. فایل `index.html` را در مرورگر باز کنید.
3. متن و پروژه‌ها را در `index.html`، ظاهر را در `styles.css` و رفتار را در `script.js` ویرایش کنید.

### ⚠️ محدودیت فعلی

برای فعال‌سازی، ایمیل مقصد را در ویژگی `data-contact-email` فرمِ `index.html` قرار دهید. فرم پیش‌نویس ایمیل را باز می‌کند؛ ارسال نهایی بر عهدهٔ کاربر است. بدون ایمیل مقصد، خطای روشن نشان داده می‌شود. برای ارسال مستقیم از سایت به backend نیاز است.

### 💡 این پروژه به چه کار می‌آید؟

برای شروع یک صفحهٔ معرفی شخصی، ساخت نمونهٔ اولیهٔ پورتفولیو یا تمرین ویرایش رابط کاربری، فایل‌های کم‌تعداد این پروژه نقطهٔ شروع مناسبی‌اند. بازدیدکننده از بخش معرفی به پروژه‌ها می‌رسد و در انتها فرم تماس را می‌بیند. داده‌های نمایشی داخل HTML قرار دارند؛ برای افزودن پروژه‌های واقعی کافی است کارت‌های موجود را جایگزین کنید.

## 🇬🇧 English

A small personal portfolio template built with HTML, CSS, and JavaScript.

### 🚀 Features

- Single-page About, Projects, and Contact sections.
- Light/dark toggle.
- Browser-side validation and an email draft for the contact form.

### 🛠️ Run and customize

1. Clone: `git clone https://github.com/AminAskariX/dynamic-portfolio-creator.git`.
2. Open `index.html` in a browser.
3. Edit copy and sample projects in `index.html`, styles in `styles.css`, and interactions in `script.js`.

### ⚠️ Current limitation

Set the recipient in the form's `data-contact-email` attribute in `index.html`. The form opens a draft in the visitor's email app; the visitor must send it. An unset recipient shows an explicit error. Direct site-side delivery requires a backend.

### 💡 Where it fits

Use this small codebase to prototype a personal site, learn front-end customization, or replace the sample project cards with your own work. Visitors can move from the introduction to the portfolio items and then the contact area. The sample content lives directly in HTML, so the starting point stays easy to inspect.

### 🧩 Repository map

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and copy |
| `styles.css` | Layout, colors, and dark mode |
| `script.js` | Theme toggle and form interaction |

> 🔎 There is no build step. Configure the recipient before publishing it as a contact channel.
